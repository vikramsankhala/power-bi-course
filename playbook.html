1. BI Vocabulary for Managers

Master these terms to communicate effectively with data teams and stakeholders.

TermDefinition
ETLExtract, Transform, Load — the process of moving data from sources into a data warehouse.
Data WarehouseCentral repository for integrated data from multiple sources, optimized for analysis.
KPIKey Performance Indicator — a measurable value that shows progress toward a business goal.
DashboardVisual display of key metrics and KPIs for at-a-glance monitoring.

DAXData Analysis Expressions — formula language in Power BI for calculations.
MeasureCalculated value (e.g., total revenue, YoY growth) computed from underlying data.
DimensionCategorical attribute (region, product, time) used to slice measures.

2. Power BI Architecture Overview

Understand how data flows from source to insight.

Data Sources → Power Query (ETL) → Data Model → DAX Measures → Visualizations → Reports & Dashboards

Key Components

  • Power BI Desktop: Free authoring tool for building reports and data models.
  • Power BI Service: Cloud platform for sharing, collaboration, and scheduled refresh.
  • Power Query: ETL tool for connecting, transforming, and cleaning data.
  • DAX: Formula language for measures and calculated columns.

3. Data Transformation Best Practices

  • Remove unnecessary columns early to improve performance.
  • Use appropriate data types (e.g., Date, Decimal, Text).
  • Create meaningful column names; avoid spaces in technical names.
  • Handle nulls and errors explicitly (Replace Values, Fill Down).
  • Document steps in Power Query for reproducibility.

4. Data Modeling Guidelines

Star Schema

Design with a central fact table (transactions, events) and dimension tables (products, customers, time).

Relationships

  • Use one-to-many relationships (dimension → fact).
  • Set correct cross-filter direction (usually single).
  • Avoid circular relationships and many-to-many when possible.

5. Essential DAX Patterns

Total Revenue:
Total Revenue = SUM(Sales[Revenue])
Year-over-Year Growth:
YoY Growth = DIVIDE([Total Revenue] - [Prior Year Revenue], [Prior Year Revenue])
Running Total:
Running Total = CALCULATE([Total Revenue], FILTER(ALL(DateTable), DateTable[Date] <= MAX(DateTable[Date])))

7. Dashboard Design Principles

  • Hierarchy: Most important metrics at top-left; drill-down details below.
  • Consistency: Use the same colors and fonts across visuals.
  • Simplicity: Avoid clutter; one main message per visual.
  • Context: Add titles, labels, and tooltips for clarity.
  • Interactivity: Use slicers and cross-filtering for exploration.

8. Managerial Decision Framework

  1. Define the question — What decision needs to be made?
  2. Identify data — What data is available and relevant?
  3. Build the view — Which visuals answer the question?
  4. Interpret — What does the data show? What are the implications?
  5. Recommend — What action should be taken?
